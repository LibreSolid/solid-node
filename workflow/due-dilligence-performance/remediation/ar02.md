# AR-02 / AR-04 artifact-identity correction

Date: 2026-09-07

Scope: the adversarial-review corrections for rigid faceted verdict identity
(AR-02) and flexible verdict identity in the presence of a stale nominal STL
(AR-04). This is implementation evidence only; the independent review record
remains authoritative for review status.

## Red evidence

The deterministic AR-02 regressions were added before the correction and run
against the then-current implementation:

```text
pytest -q \
  tests/test_persistent_piece_facts.py::LowerGeometryIdentityTest::test_direct_verdict_cannot_be_cached_under_a_later_artifact \
  tests/test_persistent_piece_facts.py::LowerGeometryIdentityTest::test_placement_bounds_and_deferred_manifold_share_one_identity
```

Result: `2 failed in 1.19s`.

- The direct comparison decoded a 1 mm box, atomically replaced that path
  with a 10 mm box before verdict-key construction, and then served the old
  empty verdict again for the replacement. Clearing only the verdict cache
  exposed the current non-empty `1.0 mm^3` intersection.
- The placement path read the old 1 mm bounds, then recorded the replacement's
  identity; its deferred Manifold therefore described the 10 mm replacement
  while the broad phase still described the 1 mm predecessor.

The independent reviewer supplied the AR-04 red diagnostic on the combined
pre-correction tree: a real Valvetrain with a valid stale box at the spring's
nominal `stl_file` compared the flexible spring and rigid retainer twice at the
same lift. `_faceted_verdict` ran once and `_verdict_cache` retained one entry.
The artifact path, rather than the evaluated flexible binding, had incorrectly
certified verdict reuse and could therefore survive a later binding change.

## Correction

- `_cached_manifold` now returns the exact strong artifact identity that
  supplied its cached bounds and Manifold.
- `_fast_geometry` carries that identity into the direct faceted verdict key;
  it explicitly carries `None` for flexible geometry, regardless of whether a
  stale file exists at the flexible node's nominal artifact path.
- `_solid_geometry` carries one observation through local bounds and placement
  construction. `_DeferredManifold` requests that same observation, so a
  placement cannot combine predecessor bounds with replacement geometry.
- The public framework API is unchanged. Two private test helpers have one
  additional return item: `_cached_manifold` now returns three items and
  `_fast_geometry` four. The current measurement harness was audited by its
  owner and does not unpack either helper.
