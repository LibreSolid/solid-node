Experimental schematic, not the full Curta CAD assembly. Wheel poses come only from mechanical coordinates computed in a worker. The rig uses measured contact windows and ideal detent transitions; it does not prove continuous 3D clearance, springs, or arbitrary gear contact.

No calculator result, operand or carry arithmetic drives these wheels. Static marks are attached to the wheel meshes. Geometry stays on the display thread; the worker receives one numeric program and returns coordinates.
