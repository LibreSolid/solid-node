# Web Viewer

## REMOVED Requirements

### Requirement: Backend server modes
**Reason**: The viewer is no longer part of solid-node. It is the separately installed, AGPL-3.0-only `solid-node-viewer` package, which owns this behaviour and specifies it.
**Migration**: See the `development-server` capability of solid-node-viewer (the OpenSCAD GUI viewer requirement moves to this repository's `cli` capability, under the develop command). Behaviour is unchanged; only the repository that specifies it moved.
