# Viewer Assembly Navigation

## REMOVED Requirements

### Requirement: A viewer host can inspect the rendered assembly
**Reason**: The viewer is no longer part of solid-node. It is the separately installed, AGPL-3.0-only `solid-node-viewer` package, which owns this behaviour and specifies it.
**Migration**: See the `viewer-assembly-navigation` capability of solid-node-viewer. Behaviour is unchanged; only the repository that specifies it moved.
